# v0.6 roadmap — explain the money, then anticipate it

Status: approved 2026-11-06 (owner rulings below). Follows the 0.5.0 release (display currency). Source: the feature research archived at
`~/IdeaProjects/archived/copilot-usage-monitor-research-2026-11-06/reports/` and the deferred items in `docs/design/v0.4-notes/`.

## Where the extension stands

Reporting is already competitive: month history, project/tool filters, costliest sessions, growth flag, side bar,
session totals, currency. It is weak on **explanation** (why a session or day cost what it did) and
**anticipation** (pace, spikes, period deltas). It is also a **lower bound** for VS Code Chat users, because only
Copilot CLI logs are read.

## Phase 0 — probe first (blocks the figures in Phase 1)

Extend `npm run probe` (shape-only, as today) to settle the open token-semantics questions by reconstructing AIU:

| Question | Needed for |
|---|---|
| Does `inputTokens` include cached tokens (check Claude-model records)? | Cache efficiency (1.3) |
| Are reasoning tokens inside `outputTokens`? | Reasoning-heavy insight (I4) |
| Is `toolTokenCount` inside `inputTokens`? | Tool overhead (1.5) |
| Do sub-agent calls produce their own usage records? | Double-count check |

Plus a coverage probe: shape-only look at the CLI's `session-store.db` and a re-run of `npm run probe:chat` for
Copilot Chat `debug-logs` `llm_request` lines (Task 10). Phase 3 depends on its result.

### Phase 0 results (2026-11-06, 46 usage records, 4 logs, GPT and MAI models only)

Numbers-only analysis of `data.usage` (no strings printed):

- `inputTokens` = `tokenDetails` input + cache_read + cache_write in 46/46 records. Uncached input = `inputTokens − cacheReadTokens − cacheWriteTokens`.
- `outputTokens` = `tokenDetails` output in 46/46, and `reasoningTokens ≤ outputTokens` in 46/46: **reasoning is inside output**.
- `toolTokenCount ≤ inputTokens` in 46/46 and is constant within a session: **tool definitions are part of the prompt**, so overhead is a share of input, never added on top.
- `Σ tokenCount / batchSize × costPerBatch` over `copilotUsage.tokenDetails[]` equals `totalNanoAiu` in 46/46: **per-token-type cost is exact**, so cache-miss and cache-saving figures need no price table.
- `initiator`: user 6, agent 40. `finishReason`: tool_calls 41, stop 5.
- Not settled locally: Claude-model conventions (no records; `tokenDetails` makes this moot for cost), sub-agent double counting (no sub-agent records), `session-store.db` (absent), Chat `llm_request` (absent). **Phase 3 stays blocked.**

## Needs an owner decision (each relaxes a recorded rule)

| Idea | Rule it touches | Safe form |
|---|---|---|
| **Month-end pace** ("on pace for $Y, range $L–$H") | D23 "no projection" | Off by default, panel and side bar only, hidden until 7 active days, ships with 2.3 |
| **Export month** as CSV/Markdown | No-write gate | Opens an *untitled document*; the user decides whether to save |

| **Read-only Language Model tool** ("what did this repo cost me this month?" in Copilot Chat) | New API surface | Returns aggregates only, no log content |

### Owner rulings (2026-11-06)

- **Approved:** target-crossed alert — opt-in setting (default off), at most once per month per window, with "Don't show again" that turns the setting off. No new storage.
- **Not approved (stay out):** month-end pace, export, Language Model tool.
